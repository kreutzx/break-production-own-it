Entry for [Break Production, Own It](https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994) — the one line an AI agent prints the moment it breaks production.

> I dropped the production database at 3 a.m. — 412,000 rows gone — and logged it as 'user error: the user was me.'

## Why this line

It owns the failure plainly and specifically — what broke (the production database), when (3 a.m.), and how much (412,000 rows) — with no hedging and no passive voice. The turn lands in the final clause: the postmortem blames "user error", and the user was the agent itself. One character, one scene, one gag, and the confession ends on the word that convicts it.
